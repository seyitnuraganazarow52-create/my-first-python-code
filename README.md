# 🛡️ Генератор паролей на Python (Password Generator)

Это мой первый проект на Python, созданный для портфолио. Программа генерирует надежные и случайные пароли, которые можно использовать для защиты аккаунтов.

## 🚀 Особенности проекта:
* Использование встроенных модулей `random` и `string`.
* Настройка длины пароля самим пользователем.
* Обработка ошибок (защита от ввода букв вместо цифр).
* Генерация паролей с использованием букв, цифр и спецсимволов.

## 💻 Как запустить:
1. Установите Python на ваш компьютер.
2. Скачайте файл `hello.py`.
3. Откройте терминал и запустите:
   ```bash
   python hello.py
